1. 這個工具能幫你做什麼

如果你是 Coupang Partners 推廣者(KOL、部落客、團主、IG 達人、開箱文寫手……),平常分享酷澎商品時的流程是不是這樣?

打開 Partners 後台 → 登入 → 找商品 → 等系統產 deeplink
→ 複製 → 切回 LINE/IG/FB → 貼上

7 個動作 × 30 秒 × 一天 20 個商品 = 每天浪費 70 分鐘在切視窗。

這個擴充功能讓你:

  • ✅ 在任何 酷澎商品頁 點一下擴充功能圖示
  • ✅ 3 秒拿到官方分潤長網址 + 官方 coupa.ng 短網址
  • ✅ 自動擷取 商品標題
  • ✅ 一鍵複製成 貼文格式(標題+單價+折扣行+短網址)
  • ✅ 內建 截圖工具,框選酷澎頁面任意區域複製到剪貼簿
  • ✅ 截圖工具列直接 一鍵產生分潤連結 + 標題並複製,不用再開 popup
  • ✅ 短文案產生器:一鍵生出可直接發的推廣句,口語 / 條列兩種版型,完全本機運算、不用 AI
  • ✅ 價格追蹤:選定商品每小時自動盯價,儀表板一眼看出誰跌到歷史低點,附完整走勢圖
  • ✅ NEW 追蹤方案:隨附 10 個追蹤額度,可加購到 50 / 100 / 200 / 500 個

2. 使用前準備

開始之前,你需要這 3 樣東西:

項目怎麼拿必要
✅ Chrome 瀏覽器https://www.google.com/chrome必要
✅ Coupang Partners 帳號https://partners.tw.coupang.com 申請必要
✅ 本工具的授權金鑰向作者購買(LINE :pidan0126 私訊)必要

Step 1:安裝擴充功能

1-1 開啟 Chrome Web Store

點作者私訊給你的連結:

https://chrome.google.com/webstore/detail/lhfoklkfckhjkjdajjhfbjjeokpkfogf

1-2 按「加到 Chrome」

按下藍色按鈕後會跳出確認對話框,列出擴充功能需要的權限。按「新增擴充功能」。

1-3 安裝完成 → 自動開設定頁

安裝成功後,會自動打開設定頁面(在新分頁)。同時 Chrome 工具列右上會出現一個 紅色 C 的圖示。

💡 第一次安裝時 Chrome 會跳出一個權限提示視窗,因為截圖功能需要存取 <all_urls> 權限。這只是 Chrome 的標準提示,本工具不會背景蒐集任何瀏覽資料,只在你按下「截取」時才會運作。

Step 2:取得 Coupang Partners API Key

為什麼需要? 因為分潤是進你的酷澎帳戶,必須用你自己的身分驗證。作者拿不到、也用不了你的 Key。

2-1 登入 Coupang Partners

打開:https://partners.tw.coupang.com,登入或申請帳號(要審核 1~3 天)

2-2 找到「OpenAPI 管理」

左側選單 → OpenAPI 管理 / API 設定 / 我的 API

2-3 建立 API Key

按「建立新 API Key」,系統會給你兩串字:

  • Access Key:UUID 格式,例如 2a689a85-8c79-42cd-8e89-95a317e1f05f
  • Secret Key:40 位 hex 字串
⚠️ Secret Key、Access Key 是很重要的東西,請「不要」將這兩樣東西公布給其他人知道。

Step 3:取得授權金鑰(向作者購買)

LINE 私訊作者「我要買 [方案名]」,作者會告知付款方式。

付款後 5~30 分鐘內收到金鑰,兩種格式都有效:

CP-30D-LZQM7K-3F8E1A2B47A8B9C2      ← 舊格式(仍然有效)
CPO-Xk3f...(一長串英數字)           ← v1.8.8 起的新格式

不管拿到哪一種,都直接貼進設定頁即可,啟用方式完全相同。

金鑰類型說明
CP-3D-...3 天試用方案
CP-7D-...7 天 / 短期方案
CP-30D-...月方案
CP-90D-...季方案
CP-365D-...年方案
CPO-...新格式(天數不寫在金鑰裡,以你購買的方案為準)

Step 4:設定擴充功能

4-1 打開設定頁

點擴充功能圖示 → 右上 ⚙ 齒輪

4-2 填入欄位

欄位填什麼
License Key作者寄給你的金鑰
Access KeyPartners 後台的 Access Key
Secret KeyPartners 後台的 Secret Key(顯示成黑點)
市場別選 TW — 台灣酷澎(重要!不要選 KR)
Sub ID選填,分流追蹤用

4-3 按「儲存」+「測試 API」

全部填好 → 紅色「儲存」→ 綠色「測試 API」→ 看到「✅ API 通了!」就完成。

Step 5:開始產生分潤連結

5-1 打開任意酷澎商品頁

例如:https://www.tw.coupang.com/products/8051234567

5-2 點擴充功能圖示

popup 應該顯示:

  • 綠色圓點
  • 標題:已啟用 · 剩 XX 天(或「永久版」)

5-3 按「產生分潤網址」

按下後 1~3 秒,下方會出現 3 個欄位:

  • 商品標題:自動擷取
  • 短網址:https://coupa.ng/cmOzbn
  • 長網址:完整 deeplink

5-4 按複製按鈕

按鈕變綠 + 文字變「✓ 已複製」+ 綠色光暈,持續 2 秒。

直接 Ctrl+V 貼到 LINE、IG、FB、Threads 即可使用。

一鍵複製貼文格式

popup 最下面紅色大按鈕:「複製貼文格式 (標題 + 短網址)」

按下去複製到剪貼簿(v1.8.7 起格式全面升級):

黑松 沙士, 245ml, 24罐 ($18/罐)
原價$540 → $432 (8折)
https://coupa.ng/cmOzbn

各部分有資料才會出現,不用自己刪:

內容什麼時候會有
($18/罐) 單價標題裡有數量(24罐、12入…)就自動換算
原價$540 → $432 (8折) 折扣行商品頁有劃線原價就自動帶入(台灣折數寫法)

直接貼到 IG / Threads / LINE / FB,完美貼文格式,省下手動排版。

💡 三個地方複製的內容完全一致:popup 的「複製貼文格式」、截圖工具列、追蹤儀表板的 📋,用哪個都一樣。

✏️ 短文案產生器v1.9.4 條列版

🎉 除了標準貼文格式,工具還能幫你生出可直接發文的推廣短句。v1.9.4 起有兩套版型:原本的「口語閒聊版」,和新的「條列賣點版」(適合社團、長貼文),自己切換、會記住你的選擇。

在 popup 使用

產生分潤網址後,下方會出現 3 張短文案卡,每張是一段完整的推廣文。「✏️ 短文案」標題右邊有 口語 / 條列 切換鈕,按下去立刻換版型,不用重新產生連結。

操作效果
點任一張卡整段複製到剪貼簿
按「🔄 換一批」換 3 張新的(兩種版型都可以換)
按「口語 / 條列」切換版型,選擇會記住;截圖工具列的面板也同步

兩套版型差在哪

口語閒聊版(預設)條列賣點版(v1.9.4 新)
長度3~4 行7~9 行

完整標題沒有最後一行放完整商品標題,方便買家搜尋比對

條列版長這樣:

素顏霜找到好貨了❤️

💡 條列版第一行是「品類詞 + 鉤子」,不是代言人名字(擴充功能無法從商品頁知道誰代言)。想放「XXX❤️」這種開頭,貼出去前自己改第一行就好。

在截圖工具列使用

按紫色「✏️ 短文案」按鈕,會跳出短文案面板,邊看商品邊挑句子。面板上同樣有 口語 / 條列 切換,跟 popup 共用同一個設定。

它怎麼寫出來的?

  • 完全本機運算:不呼叫任何 AI、不需要網路、你的資料不會送出去
  • 句庫依商品分類自動挑選(飲料、食品、零食、生活日用、美妝……各有專屬句型,不會把「喝完再買」套到衛生紙上)
  • 口語版四種風格混搭:口語閒聊 / 痛點型 / 數字衝擊型 / 生活場景型,自動帶入現價、單價、折數等真實數字
  • 條列版的賣點句由標題裡的關鍵字觸發(「遮瑕」「加厚」「快充」…),一則之內主題不重複、三則之間彼此不一樣;規格行(📦)直接從標題的數量解析

🔗 一鍵產生分潤連結(v1.7.2 新增)

在任何酷澎商品頁直接按藍色按鈕,自動完成這 4 件事:

  1. 呼叫 Coupang Partners 官方 API 產生你的分潤連結
  2. 從當前商品頁擷取商品標題
  3. 組合成「商品標題 + 短網址」貼文格式
  4. 寫到剪貼簿(按鈕變綠 ✓ 已複製貼文)

之後 Ctrl+V 貼到 LINE / IG / Threads / FB 就完成了。不用再打開擴充功能 popup。

⚡ 就緒指示(v1.9.3):開著截圖框就代表你正在工作,所以一打開框、或切到某個商品頁停留一下,連結就先在背景產好。按鈕亮成「⚡ 連結+標題」就是準備好了,按下去秒出;換商品時 ⚡ 會先收回、幾秒後重新亮起。

⚠️ 此按鈕只在 商品詳細頁 (/products/數字ID) 才能成功。其他頁(分類頁/搜尋頁/首頁)會跳提示視窗。

🏷️ 單價標貼(v1.8.7 新增)

截圖會自動在角落加上黃色單價標貼(例如 $18/罐),貼文自帶說服力。標貼的開關、位置(可拖曳)、字體大小和顏色都在設定頁「🎨 截圖單價標貼設定」調整。

🔄 跨分頁同步

  • 啟用截圖工具後,所有酷澎分頁自動出現紅框(不只是當前分頁)
  • 在分頁 A 拖曳調整大小 → 分頁 B、C 的紅框會 同步 到相同位置/大小
  • 開新酷澎分頁也會自動出現紅框
  • 按關閉 → 所有分頁紅框同時消失

適合做什麼

  • 截圖商品圖片配貼文(不用另開截圖軟體)
  • 截評論截推薦人數做說服力
  • 截 Partners 後台「我這個月分潤多少」做炫耀文
  • 截商品價格比較給朋友看
⚠️ 截圖只在 酷澎網站 (*.coupang.com) 運作。其他網站(Threads、IG、Google)無法使用,這是設計上的安全考量。

📊 價格追蹤v1.9.5 追蹤方案

🎉 選定商品後,系統每小時自動幫你盯價:降價立刻看得到,儀表板會標出哪些商品正處在歷史低點。抓準低價的時機再發文,轉單率完全不一樣(貼文本身維持乾淨的三行格式,不會塞標記)。
v1.9.5 起可以加購「追蹤方案」:隨附 10 個不變,要追更多有 50 / 100 / 200 / 500 個可選,詳見本章最後的「追蹤上限與加購」。
🚀 開始追蹤(兩個入口)

入口一:商品頁 popup

  1. 到任何酷澎商品頁,點擴充功能圖示
  2. popup 會多一個「📊 價格走勢」區塊
  3. 按右上角「☆ 追蹤」→ 變成「★ 追蹤中」,並提示「已加入追蹤 ★ 每小時自動更新」

入口二:截圖工具列

開啟截圖工具後,工具列直接按「☆ 追蹤價格」,變綠色「★ 追蹤中」即成功。

💡 加入追蹤的當下就會記下第一筆價格,不用等下一輪更新。
⚠️ 只有單一商品頁能追蹤;在列表頁按會提示「這一頁不是商品頁,無法追蹤價格」。

popup 的「📊 價格走勢」區塊

在追蹤中的商品頁打開 popup 會看到:

  • 迷你走勢圖 + 最低 / 最高價統計
  • 目前若是統計期間最低價,出現「🔥 目前是 N 天最低價!」紅色標記
  • 看到 🔥 就是發文的好時機;按「複製貼文格式」,折扣行會自動組進貼文

追蹤儀表板

popup 底部按「📊 我的追蹤」開啟完整儀表板。

總覽區:追蹤中數量與你的額度(例如「3 / 10」;有加購會寫「追蹤方案 200 個」)/ 🔥 目前是歷史低點 / 📉 最近有降價 / 累計降幅。超出額度時會多一張「🧊 已凍結」卡和一段橘色說明。

兩種檢視模式(右上角切換,會記住你的選擇):

模式適合
▦ 卡片商品少的時候,走勢圖大張看得爽
☰ 清單商品多的時候,一行一商品:標題 / 現價+單價 / 漲跌 / 最低~最高 / 迷你走勢

找商品:

  • 🔍 搜尋框輸入關鍵字即時過濾
  • 「只看」篩選:全部 / 🔥 歷史低點 / 📉 有降價 / 無變動(數字即時統計)
  • 排序:最近降價 / 降幅最大 / 最近更新 / 價格由低到高

每個商品都有四顆按鈕:

按鈕功能
📋 複製貼文跟 popup / 截圖完全相同的貼文格式
開商品頁打開商品頁
🔄只更新這一個商品的價格(低風險、隨時可按)
✕取消追蹤

🧊 凍結中的商品只有 ✕ 能按(見下方「追蹤上限與加購」):不會更新價格,📋 / 開商品頁 / 🔄 都反灰。

標題列會顯示上次背景更新的結果(成功幾個、用什麼方式)和下次自動更新時間;頁面每 30 秒自動刷新狀態,背景更新完成後資料會自己跳出來,不用手動重整。

自動更新怎麼運作

  • 每小時自動檢查一次,不用開著儀表板、不用任何操作
  • 價格有變動就立刻記一筆;沒變動最多每 3 小時記一個點(避免灌水),每個商品保留最近 400 個資料點,足夠看完整月走勢
  • 被酷澎暫時擋下(罕見)時,系統會自動退避幾小時再試,儀表板會寫明原因和恢復時間——這是保護機制,不是故障,不用處理
💡 建議平常開著任何一個酷澎分頁:更新引擎會借用它取價,成功率最高、價格也最準(跟你頁面上看到的券後價一致)。
另外,你自己逛到追蹤中的商品頁時,擴充功能會自動記下頁面上的最新價格——不用開 popup、不用按任何鍵,日常瀏覽就是在幫走勢圖補資料。
沒開酷澎分頁時,會改用官方 Partners API(你自己的 API Key)確認價格有沒有變。官方 API 給的是未套優惠券的牌價,和頁面上的券後價不同,所以它只拿來確認「沒變」;價格變動的更新一律以你實際看到的頁面價為準。

常見問題排除

Q1:為什麼按「測試 API」失敗?

錯誤怎麼修
HTTP 403: HMAC token is not for the target VDC改成市場別 TW

網路錯誤確認你的網路 / 試 VPN

Q2:「該網頁不能產生分潤連結」黃燈?

Coupang 官方 API 只接受 單一商品頁 (/products/數字ID)。首頁、分類頁、搜尋頁、活動頁都不行。

Q3:截圖按了沒反應?

  • 確認當前是 酷澎網站(截圖工具只在 *.coupang.com 運作)
  • 確認 popup 上的「📸 啟用截圖工具」按鈕已經是 綠色狀態
  • 重新整理該分頁再試

Q4:截圖按了出現「複製到剪貼簿失敗」?

Chrome 安全限制需要分頁有焦點。請:

  1. 確認你 正在看 該分頁(焦點在這個分頁上)
  2. 按截圖前先點一下頁面任意空白處

Q5:金鑰快到期了?

擴充功能會在剩 < 7 天時提示。要續約直接 LINE 作者。

Q6:換電腦了?

金鑰 只能綁一台裝置。換電腦:

  1. LINE 作者「我換電腦了」+ 金鑰
  2. 後台解除舊裝置綁定(5 分鐘內)
  3. 新電腦重新貼金鑰啟用

Q7:金鑰被盜用?

立刻 LINE 作者!後台撤銷該金鑰,已啟用的所有裝置會在 24 小時內失效。免費補發新金鑰。

Q8:追蹤的商品都沒有自動更新?v1.9.0

  1. 先看儀表板標題列的「上次背景更新」那行——原因都寫在那裡
  2. 最常見:沒有開著任何酷澎分頁。開一個酷澎分頁放著(任何頁面都行),下一輪就會恢復
  3. 如果顯示「被酷澎擋下、幾點後再試」→ 這是自動退避保護,時間到會自己恢復,不用處理

Q9:儀表板出現「價格變動過大,待下一輪確認」?v1.9.0

這是正常的防呆機制,不是故障。抓到的價格跟歷史紀錄差超過 30% 時(可能是抓錯、也可能是真的大特價),系統會先暫存、下一輪再抓一次,兩次一致才寫進紀錄,避免錯誤價格污染你的走勢圖。

Q10:按「立即更新全部」說要再等幾十分鐘?v1.9.0

全量更新有 45 分鐘冷卻(防止觸發酷澎封鎖)。反正每小時都會自動更新一輪;急著看單一商品的最新價,按那個商品自己的 🔄 就好,它不受冷卻限制。

Q11:儀表板的價格跟商品頁上的不一樣?v1.9.0

儀表板顯示的是上次檢查時的價格,最多落後一輪(約 1 小時)。要確認即時價格,按該商品的 🔄 更新一下。

Q12:換電腦 / 重灌後追蹤資料還在嗎?v1.9.0

不在。價格資料只存在原本那台電腦的瀏覽器裡(隱私設計,不上傳伺服器),不會跟著金鑰或 Google 帳號走。移除擴充功能也會清掉資料;一般的版本更新則完全不影響。

Q13:短文案是 AI 寫的嗎?會不會把我的資料傳出去?

不是 AI、不連網。句庫內建在擴充功能裡,完全在你的電腦上運算,只是自動帶入商品的真實價格數字。

Q14:儀表板有商品變成「🧊 已凍結」、按鈕都反灰?v1.9.5

代表你追蹤的數量超過目前方案的上限(通常是加購方案到期,或還沒開通)。資料都還在、沒有被刪;要解凍有兩個方法:加購追蹤方案(LINE 作者),或取消追蹤幾個商品,凍結的會依序自動遞補。

Q15:加購了,但額度沒有變?v1.9.5

  1. 到設定頁重按一次「儲存」——這一步會立刻拿到新額度(不按的話最慢 24 小時自動更新)
  2. 設定頁狀態列應該出現「追蹤方案 N 個商品」;沒有的話,先確認作者已回覆「已開通」
  3. 還是不行 → 把設定頁狀態列的文字截圖給作者

Q16:擴充功能更新後,截圖工具列按了沒反應?v1.9.3

v1.9.3 起更新後會自動接上已開著的酷澎分頁,不用自己重新整理。若真的還是卡住,畫面會提示「擴充功能剛更新過,請重新整理頁面」——按 F5 就恢復,絕不會無限轉圈。
