1. 這個工具能幫你做什麼

如果你是 Coupang Partners 推廣者(KOL、部落客、團主、IG 達人、開箱文寫手……),平常分享酷澎商品時的流程是不是這樣?

打開 Partners 後台 → 登入 → 找商品 → 等系統產 deeplink
→ 複製 → 切回 LINE/IG/FB → 貼上

7 個動作 × 30 秒 × 一天 20 個商品 = 每天浪費 70 分鐘在切視窗。

這個擴充功能讓你:

  • ✅ 在任何 酷澎商品頁 點一下擴充功能圖示
  • ✅ 3 秒拿到官方分潤長網址 + 官方 coupa.ng 短網址
  • ✅ 自動擷取 商品標題
  • ✅ 一鍵複製成 貼文格式(標題+短網址)
  • ✅ NEW 內建 截圖工具,框選酷澎頁面任意區域複製到剪貼簿

2. 使用前準備

開始之前,你需要這 3 樣東西:

項目怎麼拿必要
✅ Chrome 瀏覽器https://www.google.com/chrome必要
✅ Coupang Partners 帳號https://partners.tw.coupang.com 申請必要
✅ 本工具的授權金鑰向作者購買(LINE :pidan0126 私訊)必要

Step 1:安裝擴充功能

1-1 開啟 Chrome Web Store

點作者私訊給你的連結:

https://chrome.google.com/webstore/detail/lhfoklkfckhjkjdajjhfbjjeokpkfogf

1-2 按「加到 Chrome」

按下藍色按鈕後會跳出確認對話框,列出擴充功能需要的權限。按「新增擴充功能」。

1-3 安裝完成 → 自動開設定頁

安裝成功後,會自動打開設定頁面(在新分頁)。同時 Chrome 工具列右上會出現一個 紅色 C 的圖示。

💡 第一次安裝時 Chrome 會跳出一個權限提示視窗,因為截圖功能需要存取 <all_urls> 權限。這只是 Chrome 的標準提示,本工具不會背景蒐集任何瀏覽資料,只在你按下「截取」時才會運作。

Step 2:取得 Coupang Partners API Key

為什麼需要? 因為分潤是進你的酷澎帳戶,必須用你自己的身分驗證。作者拿不到、也用不了你的 Key。

2-1 登入 Coupang Partners

打開:https://partners.tw.coupang.com,登入或申請帳號(要審核 1~3 天)

2-2 找到「Partners API」

上方選單 → 工具 / Partners API / API憑證

在「API憑證」,系統會給你兩串字:

  • Access Key:UUID 格式,例如 2a689a85-8c79-42cd-8e89-95a317e1f05f
  • Secret Key:40 位 hex 字串
⚠️ Secret Key、Access Key 是很重要的東西,請「不要」將這兩樣東西公布給其他人知道。

Step 3:取得授權金鑰(向作者購買)

LINE 私訊作者「我要買 [方案名]」,作者會告知付款方式。

付款後 5~30 分鐘內收到金鑰,格式:

CP-30D-LZQM7K-3F8E1A2B47A8B9C2
金鑰類型說明
CP-7D-...3 天試用 / 試用方案
CP-7D-...7 天 / 短期方案
CP-30D-...月方案
CP-90D-...季方案
CP-365D-...年方案

Step 4:設定擴充功能

4-1 打開設定頁

點擴充功能圖示 → 右上 ⚙ 齒輪

4-2 填入欄位

欄位填什麼
License Key作者寄給你的金鑰
Access KeyPartners 後台的 Access Key
Secret KeyPartners 後台的 Secret Key(顯示成黑點)
市場別選 TW — 台灣酷澎(重要!不要選 KR)
Sub ID選填,分流追蹤用

4-3 按「儲存」+「測試 API」

全部填好 → 紅色「儲存」→ 綠色「測試 API」→ 看到「✅ API 通了!」就完成。

Step 5:開始產生分潤連結

5-1 打開任意酷澎商品頁

例如:https://www.tw.coupang.com/products/8051234567

5-2 點擴充功能圖示

popup 應該顯示:

  • 綠色圓點
  • 標題:已啟用 · 剩 XX 天(或「永久版」)

5-3 按「產生分潤網址」

按下後 1~3 秒,下方會出現 3 個欄位:

  • 商品標題:自動擷取
  • 短網址:https://coupa.ng/cmOzbn
  • 長網址:完整 deeplink

5-4 按複製按鈕

按鈕變綠 + 文字變「✓ 已複製」+ 綠色光暈,持續 2 秒。

直接 Ctrl+V 貼到 LINE、IG、FB、Threads 即可使用。

一鍵複製貼文格式

popup 最下面紅色大按鈕:「複製貼文格式 (標題 + 短網址)」

按下去複製到剪貼簿:

黑松 沙士, 245ml, 24罐
https://coupa.ng/cmOzbn

直接貼到 IG / Threads / LINE / FB,完美貼文格式,省下手動排版。

🔄 跨分頁同步

  • 啟用截圖工具後,所有酷澎分頁自動出現紅框(不只是當前分頁)
  • 在分頁 A 拖曳調整大小 → 分頁 B、C 的紅框會 同步 到相同位置/大小
  • 開新酷澎分頁也會自動出現紅框
  • 按關閉 → 所有分頁紅框同時消失

適合做什麼

  • 截圖商品圖片配貼文(不用另開截圖軟體)
  • 截評論截推薦人數做說服力
  • 截 Partners 後台「我這個月分潤多少」做炫耀文
  • 截商品價格比較給朋友看
⚠️ 截圖只在 酷澎網站 (*.coupang.com) 運作。其他網站(Threads、IG、Google)無法使用,這是設計上的安全考量。

常見問題排除

Q1:為什麼按「測試 API」失敗?

錯誤怎麼修
HTTP 403: HMAC token is not for the target VDC改成市場別 TW
HTTP 401Access/Secret Key 錯,重新從 Partners 後台複製
網路錯誤確認你的網路 / 試 VPN
金鑰簽章錯誤跟作者確認金鑰是不是寄錯

Q2:「該網頁不能產生分潤連結」黃燈?

Coupang 官方 API 只接受 單一商品頁 (/products/數字ID)。首頁、分類頁、搜尋頁、活動頁都不行。

Q3:截圖按了沒反應?

  • 確認當前是 酷澎網站(截圖工具只在 *.coupang.com 運作)
  • 確認 popup 上的「📸 啟用截圖工具」按鈕已經是 綠色狀態
  • 重新整理該分頁再試

Q4:截圖按了出現「複製到剪貼簿失敗」?

Chrome 安全限制需要分頁有焦點。請:

  1. 確認你 正在看 該分頁(焦點在這個分頁上)
  2. 按截圖前先點一下頁面任意空白處

Q5:金鑰快到期了?

擴充功能會在剩 < 7 天時提示。要續約直接 LINE 作者。

Q6:換電腦了?

金鑰 只能綁一台裝置。換電腦:

  1. LINE 作者「我換電腦了」+ 金鑰
  2. 後台解除舊裝置綁定(5 分鐘內)
  3. 新電腦重新貼金鑰啟用

Q7:金鑰被盜用?

立刻 LINE 作者!後台撤銷該金鑰,已啟用的所有裝置會在 24 小時內失效。免費補發新金鑰。

帳戶管理

換電腦流程

  1. LINE 作者「我要換電腦」+ 金鑰
  2. 作者後台解除舊裝置
  3. 新電腦安裝擴充功能 → 設定頁貼同支金鑰 → 啟用成功
    4. 解除綁定金鑰只限一次

續約流程

  1. 收到「快到期」提醒
  2. LINE 作者「我要續約 [方案]」
  3. 付款 → 收新金鑰
  4. 設定頁把舊金鑰換成新的 → 儲存
  5. 無縫接續

撤銷自己的金鑰

  1. LINE 作者「請撤銷我的金鑰」
  2. 後台一鍵撤銷
  3. 24 小時內失效
  4. 免費補發新金鑰

安全與隱私

  • ✅ API Key 只存在 Chrome 的 chrome.storage.sync,加密儲存
  • ✅ 作者 看不到也拿不到 你的 API Key
  • ✅ 所有 API 呼叫從你瀏覽器 直接 送到 Coupang 官方,不經過第三方
  • ✅ 截圖功能:只在你按下「截取」時 才複製剪貼簿,不會背景偷拍
